YesPDF On-Prem — Release History

Highlights, improvements and fixes across releases of your on-premises PDF management platform.

1.7 Series — Enterprise Maturity

1.7.6.xAug 19–20, 2026
New FeatureSecurity

Queue instead of reject, and enterprise hardening

  • Concurrent-user (CCU) queue. When the licence limit is reached, users are no longer turned away; they enter a fair FIFO queue and are admitted automatically when a seat frees up. The idle threshold shortens while someone is waiting; only the user identity is held in the queue, never a password.
  • Manual group membership. Local (non-directory) accounts can now be assigned groups and tool permissions manually; manually assigned memberships are preserved across directory synchronisation.
  • Trusted-proxy support and a “How do you see me?” diagnostic screen to verify network/header configuration.
  • Hardening after an independent security test. Findings from a third-party penetration test were resolved with central, lasting solutions rather than point patches.
  • Scanned document → editable PDF: reliability fix. A bug that could occasionally interrupt watermarking, form-field and small-scan OCR operations was fixed; these now complete reliably.
1.7.5.xAug 11–17, 2026
New FeatureSecurityCompatibility

Windows SSO, MSSQL Kerberos and group-based authorisation

  • Windows SSO (Negotiate / SSPI). Single sign-on with the domain session; no extra dependency. Off by default and no automatic redirect, as a deliberate security choice.
  • Windows authentication to MSSQL (Kerberos). Works end to end with a service account; the database password is stored nowhere.
  • Group-based tool authorisation (RBAC). Group-to-tool mapping over LDAPS for large directories (synchronisation at the scale of 10,000 users and 158 groups).
1.7.4.xAug 6–7, 2026
ImprovementPerformance

Stability fixes and a smaller installer

  • Various stability fixes: the UDF→Word tool can be closed, queue limits show correctly in the UI, and the rate limit behaves consistently.
  • Installer reduced from 1278 MB to 1128 MB (~150 MB smaller).
1.7.3.0Jul 23, 2026
New FeatureImprovement

Print-file (PS/EPS) conversion and a System Engines diagnostics screen

  • Print File → PDF (PS/EPS). A new card in Tools: PostScript (.ps) and EPS (.eps) files are converted to PDF with a single drag-and-drop click and saved to “My Documents.” Conversion runs in a separate, sandboxed (−dSAFER) process with signature validation and size/timeout guards, powered by a dedicated conversion engine (not bundled; installed separately on the server and configured in .env). The API upload path also accepts PS/EPS and converts automatically.
  • System Engines diagnostics screen. A new “System Engines” category under Admin > Settings shows the PDF engine, OCR module, installed Tesseract languages, the PS/EPS conversion engine and Python versions/status on a single read-only screen.
  • Admin lockout safety (CCU). Even when all concurrent-user seats are taken, administrator sign-ins are exempt from the seat limit — access to system administration is never lost when the license is full.
  • Enterprise signing error messages. A clear message when the PFX password is wrong; a pre-check and a visible red warning as soon as a PFX is selected.
  • Fixes. Double-click protection for single-delete in the archive (the action now runs once); LDAP first-run sync (source status) fixed on new installations. The .env configuration (database, SSL, secret key) is preserved on upgrade.
1.7.2.1Jul 13, 2026
Performance

Multi-core acceleration for editable conversion

  • “Make Editable” for scanned documents is now up to 4× faster thanks to parallel OCR pre-processing (a 47-page sample document dropped from ~23 min to ~5 min).
  • OCR parallelism is configurable to match the server hardware on multi-core machines.
1.7.2.0Jul 13, 2026
New FeatureSecurity

Make scanned PDFs editable — next-generation engine

  • Faithful-overlay technology: scanned documents become editable while the original image is preserved — stamps, seals and signatures stay exactly in place, and text can be edited word by word.
  • Quality confidence score: every conversion reports how much of the document was made reliably editable.
  • Smart document detection: digitally created (non-scanned) documents are protected from unnecessary processing.
  • Automatic orientation correction for rotated scanned pages.
  • Word-level font matching with bold and serif typeface detection.
  • Installation packages and application components are now code-signed (Authenticode with timestamping).

1.5 Series — Core Platform

Core

Foundations of the on-premises PDF management platform
