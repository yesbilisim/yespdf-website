📜 Normes de signature

Signatures numériques conformes PAdES

YesPDF met en œuvre la norme PAdES (ETSI EN 319 142), garantissant la validité juridique dans tous les États membres de l’UE et les juridictions internationales.

Niveau Norme Ce qu’il apporte Cas d’usage
PAdES-B De base Signature numérique avec vérification de l’identité du signataire Documents internes, signature courante
PAdES-T Horodatage Signature + preuve d’horodatage de confiance RFC 3161 Contrats, documents juridiques, dépôts réglementaires
PAdES-LT Long terme Signature + horodatage + données de révocation intégrées Archivage, validation à long terme (plus de 10 ans)

Tous les niveaux de signature produisent des fichiers PDF vérifiables dans Adobe Acrobat, Foxit Reader et tout lecteur conforme PAdES. Aucun plug-in propriétaire requis.

⚙ Fonctionnalités clés

Tout ce qu’il faut pour signer à grande échelle

Des certificats personnels au traitement par lots automatisé, YesPDF couvre tous les scénarios de signature en entreprise.

👤

Signature par certificat personnel

Importez des certificats .p12/.pfx. Signature en un clic avec motif et lieu configurables. Placement visuel de la signature par glisser-déposer. Mots de passe chiffrés AES-256 au repos.

🏢

Pool de certificats d’entreprise

Gestion partagée des certificats avec contrôle d’accès par rôle et par groupe. Suivi des échéances avec alertes automatiques à 30, 15, 7 et 1 jour avant l’expiration.

📋

Politiques de signature

Appliquez des règles à l’échelle de l’organisation : niveau PAdES minimum, champs motif/lieu obligatoires, certificats par défaut. Appliquées par rôle, par groupe ou globalement.

📦

Signature par lots

Signez des centaines de documents en une seule fois. Lot synchrone dans l’interface avec progression en temps réel, ou file asynchrone pour des milliers de documents en traitement en arrière-plan.

📂

Signature par dossier actif

Déposez des PDF dans un dossier surveillé — signés automatiquement. Contrôles de stabilité des fichiers, chemins d’entrée/sortie configurables, plusieurs dossiers actifs avec différents certificats.

✅

Vérification des signatures

Vérifiez toutes les signatures intégrées : intégrité du document, identité du signataire, statut de confiance, niveau PAdES, validité de l’horodatage et expiration du certificat. Résultats par code couleur.

⏰

Gestion de l’expiration des certificats

Surveillance proactive avec alertes échelonnées (30/15/7/1 jour). Certificats expirés désactivés automatiquement. Les dossiers actifs ignorent automatiquement les certificats expirés. Notifications par tableau de bord et par e-mail.

🔧

Panneau d’administration

Configuration complète depuis le web : gestion CRUD des certificats, politiques de signature, gestion des dossiers actifs, configuration TSA, paramètres par défaut et tableau de bord statistique en temps réel.

Contrôle de stabilité des fichiers

Ne traite que les fichiers dont l’écriture est terminée. Évite de signer un fichier en cours de copie lors des transferts réseau.

👑

Élection de leader (haute disponibilité)

L’élection de leader basée sur la base de données garantit qu’une seule instance traite les fichiers dans les déploiements à charge répartie. Bascule automatique en ~30 secondes.

📊

Piste d’audit complète

💻 REST API

Intégrez la signature à n’importe quel flux de travail

API REST sans état pour la signature programmatique, la vérification et le traitement par lots. Authentification par clé API avec permissions par périmètre.

POST /api/v1/signing/sign-and-return 
// Signer un PDF et le renvoyer immédiatement
// Aucun document stocké sur le serveur

Content-Type: multipart/form-data
X-API-Key: your-api-key

file: invoice.pdf
certificate_id: 5
p12_password: ****
pades_level: pades-t
reason: Approuvé
location: Istanbul

→ Réponse : PDF signé en binaire
POST /api/v1/signing/batch 
// Signature par lots asynchrone
{
  "document_ids": [101, 102, 103, ...],
  "certificate_id": 5,
  "pades_level": "pades-t"
}

→ Réponse : ID de tâche pour le suivi
GET /api/v1/signing/verify/{document_id} 
// Vérifier toutes les signatures d’un document

→ Réponse : tableau JSON des détails de signature
   (signataire, intégrité, confiance, horodatages)
