📜 Signature Standards

PAdES-konforme digitale Signaturen

YesPDF implementiert den PAdES-Standard (ETSI EN 319 142) und gewährleistet die rechtliche Gültigkeit in allen EU-Mitgliedstaaten und internationalen Rechtsordnungen.

Stufe Standard Was es bietet Anwendungsfall
PAdES-B Basis Digitale Signatur mit Identitätsprüfung des Unterzeichners Interne Dokumente, Routinesignierung
PAdES-T Zeitstempel Signatur + RFC 3161 vertrauenswürdiger Zeitstempelnachweis Verträge, Rechtsdokumente, behördliche Einreichungen
PAdES-LT Langfristig Signatur + Zeitstempel + eingebettete Widerrufsdaten Archivierung, Langzeitvalidierung (10+ Jahre)

Alle Signaturstufen erzeugen PDF-Dateien, die verifizierbar sind in Adobe Acrobat, Foxit Reader und jedem PAdES-konformen Viewer. Keine proprietären Plugins erforderlich.

⚙ Key Capabilities

Alles was Sie für das Signieren im großen Maßstab benötigen

Von persönlichen Zertifikaten bis zur automatisierten Stapelverarbeitung deckt YesPDF jedes Enterprise-Signaturszenario ab.

👤

Persönliche Zertifikatssignierung

Laden Sie .p12/.pfx-Zertifikate hoch. Ein-Klick-Signierung mit konfigurierbarem Grund und Ort. Visuelle Signaturplatzierung per Drag-and-Drop. Passwörter im Ruhezustand mit AES-256 verschlüsselt.

🏢

Unternehmens-Zertifikatspool

Gemeinsame Zertifikatsverwaltung mit rollen- und gruppenbasierter Zugriffskontrolle. Ablaufverfolgung mit automatischen Benachrichtigungen 30, 15, 7 und 1 Tag vor Ablauf.

📋

Signierungsrichtlinien

Setzen Sie organisationsweite Regeln durch: minimales PAdES-Level, Pflichtfelder für Grund/Ort, Standardzertifikate. Angewendet pro Rolle, pro Gruppe oder global.

📦

Stapelsignierung

Signieren Sie Hunderte von Dokumenten auf einmal. Synchroner UI-Stapel mit Echtzeit-Fortschritt oder asynchrone Warteschlange für Tausende von Dokumenten über Hintergrundverarbeitung.

📂

Hot-Folder-Signierung

Legen Sie PDFs in einen überwachten Ordner — automatisch signiert. Dateistabilitätsprüfungen, konfigurierbare I/O-Pfade, mehrere Hot Folders mit verschiedenen Zertifikaten.

✅

Signaturverifizierung

Verifizieren Sie alle eingebetteten Signaturen: Dokumentenintegrität, Unterzeichneridentität, Vertrauensstatus, PAdES-Level, Zeitstempelgültigkeit und Zertifikatsablauf. Farbcodierte Ergebnisse.

⏰

Zertifikatsablaufverwaltung

Proaktive Überwachung mit gestaffelten Benachrichtigungen (30/15/7/1 Tag). Abgelaufene Zertifikate werden automatisch deaktiviert. Hot Folders überspringen automatisch abgelaufene Zertifikate. Dashboard- und E-Mail-Benachrichtigungen.

🔧

Admin-Einstellungspanel

Vollständige webbasierte Konfiguration: Zertifikat-CRUD, Signierungsrichtlinien, Hot-Folder-Verwaltung, TSA-Konfiguration, Standardeinstellungen und Echtzeit-Statistik-Dashboard.

Dateistabilitätsprüfung

Verarbeitet nur Dateien, die fertig geschrieben sind. Verhindert das Signieren während des Kopierens bei Netzwerkübertragungen.

👑

Leader-Election (HA)

Datenbankbasierte Leader-Election stellt sicher, dass genau eine Instanz Dateien in lastverteilten Bereitstellungen verarbeitet. Automatisches Failover in ~30 Sekunden.

📊

Vollständiges Prüfprotokoll

Jede verarbeitete Datei wird mit Status, Dateigröße, Verarbeitungszeit, verwendetem Zertifikat und Unterzeichneridentität protokolliert.

💻 REST API

Integrieren Sie Signierung in jeden Workflow

Zustandslose REST API für programmatische Signierung, Verifizierung und Stapelverarbeitung. API-Schlüssel-authentifiziert mit bereichsbasierten Berechtigungen.

POST /api/v1/signing/sign-and-return 
// PDF signieren und sofort zurückgeben
// Kein Dokument auf dem Server gespeichert

Content-Type: multipart/form-data
X-API-Key: your-api-key

file: invoice.pdf
certificate_id: 5
p12_password: ****
pades_level: pades-t
reason: Approved
location: Istanbul

→ Response: Signed PDF binary
POST /api/v1/signing/batch 
// Asynchrone Stapelsignierung
{
  "document_ids": [101, 102, 103, ...],
  "certificate_id": 5,
  "pades_level": "pades-t"
}

→ Response: Job ID for polling
GET /api/v1/signing/verify/{document_id} 
// Alle Signaturen in einem Dokument verifizieren

→ Response: JSON array of signature details
   (signer, integrity, trust, timestamps)
